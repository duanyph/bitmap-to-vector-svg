# 位图转矢量 SVG

把彩色插画 / 贴纸 / 动漫立绘 / 图标转成**真正可编辑的矢量 SVG**——分层色块是独立
`<path>` + `fill`，线稿是单条 `stroke` 路径，不是把位图塞进 `<image>` 的假矢量。

```
输入：彩色位图（original.jpg）+ 由它重绘的干净线稿（lineart_src.png）
输出：分层成品 SVG
     ├── <rect>                 白底
     ├── <g id="fills-base">    底层补齐（C：泛洪分区 + 边缘吸附，补背景/开环）
     ├── <g id="fills-main">    主基底（B：骨架环面遍历，闭合区色块天生贴线）
     └── <path id="lineart">    线稿（单 path，统一线宽）
```

## 快速开始

### 1. 环境

```bash
pip install -r requirements.txt     # numpy scipy scikit-image Pillow matplotlib
```

Python 3.8+。不依赖 potrace / vtracer —— 矢量化引擎为自研实现。

### 2. 准备素材

```bash
mkdir -p output
# 用生图工具把原图重绘成归一化线稿，另存为 output/lineart_src.png
# 原彩图另存为 output/original.jpg（取色来源）
```

### 3. 一条命令跑全流程

```bash
python pipeline.py --stage all --name myart
```

固定流程，算法参数全部内置为定稿配置，无需也无法调整。

### 产物（默认输出到 `./output/`，可用 `--outdir` 修改）

| `myart_normmask.png` | 归一化线稿掩膜（上色前置） |

## 处理流程

### 阶段 1：抽线稿（生图工具，不是本地 CV）

本地古典 CV 抽取（黑帽变换 / XDoG / 照度平坦化）在插画上必然被阴影、噪点、抗锯齿污染。
正解是用生图工具把原图重绘成线稿，提示词**必须声明"线条归一化"**：

1. 全图所有线条**同一恒定线宽**（无粗细变化、无笔锋、无压感）
2. **纯黑白二值**（禁灰阶、抗锯齿灰边、阴影、渐变、涂色、网点）
3. 轮廓**闭合**、结构完整、不增删元素
4. 白底、无噪点

原因：后续管线会把线条统一重渲染成固定线宽再骨架化，原线稿粗细不均时会在粗线处
产生分叉 / 毛刺，拟合基元数暴涨。

### 阶段 2：线稿矢量化（顺序固定，不可调换）

1. **二值化** — 阈值 200（AI 线稿的细线是抗锯齿浅灰像素，灰度中位约 167，用 128 会整条切掉）
2. **位图断缝修复：方向判据桥接** — 仅短碎片发起；桥连线须与参照侧笔画局部走向 |cos| ≥ 0.8
   才连。语义是"沿笔画走向续接"，不是"距离近就连"
3. **骨架化** + 剪毛刺 + 去小连通域
4. **统一宽度重渲染** — 全体线条统一 2.0px，骨架拓扑零损失
5. **再骨架化 → 追踪点列**（结点处自动拆笔）
6. **合并点列**（≤2px，短笔画发起 + 单趟贪心）
7. **降低线曲率**（点列级：顶点到弦垂距 <0.75px 拉向弦中点，3 轮）——必须在合并之后
8. **删除孤立噪点**（5px 内无其它笔画的点）——必须放最后
9. **拟合** — RDP 抽稀 → 拐角检测 → DP 最优分段 → 基元分级 L/A/C → 单一 path 输出

### 阶段 3：颜色填充

- **配准**：线稿是重绘版、彩图是原尺寸，先做 FFT 互相关配准（墨迹 vs 梯度），
  参数缓存在 `output/_regist.json`
- **分区与取色**：墙 = dilate(线稿, 2px)，泛洪分区 + 小块并入最大邻接域；
  取色 = 区域内部（到边界 >1.5px）像素中位数，不限调色板
- **渐变**：大区（>20000px² 且亮度 std>14）按亮度分 N 挡分层过渡 + 整区打底
- **合成**：B 主基底，C 只补 B 未覆盖的区域（底层），线稿在最上

## 命令行参数（正式版只暴露作业控制参数）

| 参数 | 默认 | 说明 |
|---|---|---|
| `--stage` | `all` | `lineart`（只线稿）/ `fill`（只上色）/ `all` |
| `--name` | `out` | 产物名前缀 |
| `--src-lineart` / `--src-color` | 自动探测 | 输入文件；缺省在输出目录找 `lineart_src.png` / `original.jpg` |
| `--outdir` | `./output` | 输出目录 |

**算法参数全部固定为定稿配置，不提供调参入口。** 定稿值：二值化阈值 200、统一线宽 2px、
桥接 gap=3/长侧/cos≥0.8、合并点列 ≤2px、降曲率垂距 0.75px、孤立噪点 5px、渐变 3 挡、
上色固定 B+C（B 主基底 + C 补齐未覆盖区域）。

上色结构（固定）：B（骨架环面遍历）画闭合区色块，边缘天生贴线；C（泛洪分区 + mask 级
边缘吸附）作底层补齐 B 未覆盖的背景/开环；线稿在最上层。这是体积与色差的定稿平衡点。

## 项目结构

```
.

├── debug_coverage.py      # 保真度验证工具（cKDTree 覆盖率）
├── requirements.txt
├── dist/                  # 技能分发包 bitmap-to-vector-svg.zip
├── output/                # 输入素材 + 产物 + README 清单
└── demo_*/diag_*/sweep_*  # 历史实验脚本（留档，能力已并入主程序）
```

## 已知限制

- **真实照片 / 连续色调扫描件**：当前 path 填充管线做不到照片级渐变，需另开渐变 mesh 路线
- 输出线宽统一，未还原原图粗细变化；闭合笔画检出为 0（交叉拆环）
- 中心线提取只支持 x 单调笔画；分叉 / Y 型交叉 / 多笔画连通区域待扩展
- 性能：全流程约 160s（线稿 ~80s，其中拟合 ~46s；上色 ~80s）
